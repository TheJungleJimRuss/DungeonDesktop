# 04: Custom entries

**What to build:** The DM can create custom monsters, spells and items, or duplicate an SRD entry into a custom one and edit it. Custom entries live in the Campaign, appear in global search marked as custom, display with the same layouts as SRD entries, and are included in Campaign export and import.

**Blocked by:** 02 SRD data and monster search

**Status:** done

- [x] Create, edit and delete custom monsters, spells and items
- [x] Duplicate any SRD entry into an editable custom one
- [x] Custom entries appear in search, clearly marked custom
- [x] Custom monsters use the same Stat Block shape and layout as SRD monsters, so Combat can treat them identically
- [x] Per-Campaign isolation, persistence across reload, included in export and import
- [x] Custom entry changes appear in a Pop-out Window without reload
