# 11: Concentration, legendary and lair actions

**What to build:** The DM marks a combatant as concentrating and is reminded to call for a save when that combatant takes damage. Legendary actions are shown with remaining uses per round, and lair actions are flagged at initiative count 20.

**Blocked by:** 08 HP and defeat, 09 Stat Block beside the tracker

**Status:** done

- [x] Mark and clear concentration on a combatant, with the spell name optional
- [x] Damage to a concentrating combatant shows a reminder with the DC to call for (the higher of 10 or half the damage)
- [x] Legendary-action creatures show remaining uses and reset on their turn start
- [x] Creatures with lair actions add an initiative-20 entry the DM can use or dismiss
- [x] Persisted with the Encounter across reload
