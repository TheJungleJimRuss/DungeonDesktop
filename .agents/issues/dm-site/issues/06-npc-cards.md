# 06: NPC cards

**What to build:** In Prep mode the DM can create and manage NPC cards (name, role, appearance, motivation, secrets, notes), tag them with a location name and faction, search and filter them, and mark secrets as revealed.

**Blocked by:** 03 Dashboard and Mode switcher

**Status:** done

- [x] Create, edit and delete NPC cards in Prep mode
- [x] Search by name and filter by faction or location tag
- [x] Each secret can be marked revealed or hidden
- [x] Persisted per Campaign and included in export and import
- [x] The NPC list and card are separate panels (so they can be popped out later)
