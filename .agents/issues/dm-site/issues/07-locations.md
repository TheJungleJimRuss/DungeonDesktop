# 07: Locations

**What to build:** The DM can create locations as World Map nodes with notes, and link NPCs to a location. A location's view shows its notes and the NPCs there. Distances and travel arrive in a later slice; here nodes need no edges.

**Blocked by:** 06 NPC cards

**Status:** done

- [x] Create, edit and delete locations with notes
- [x] Link and unlink NPCs to a location; the NPC's location tag uses the real location
- [x] A location view lists its linked NPCs
- [x] Deleting a location handles its NPC links without data loss
- [x] Persisted per Campaign and included in export and import
